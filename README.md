# Anturno releases

Releases of [Anturno](https://download.anturno.cloud), the desktop app for running coding agents.

```sh
curl -fsSL https://download.anturno.cloud/install.sh | sh
```

macOS on Apple silicon, and x64 Linux (`.deb`, AppImage, `.tar.gz`). Each release carries `SHA256SUMS` and `latest.json`, the signed manifest the app updates from. Built and published by the factory's release workflow; the `gh-pages` branch is download.anturno.cloud.
